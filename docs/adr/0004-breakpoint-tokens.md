# 0004. Breakpoint tokens checked against the CSS

- **Status:** Accepted
- **Date:** 2026-11-18

## Context

`Dialog` and `Toast` hard-code `639px` / `640px`, and `Sheet` will need the same breakpoint. A
custom property cannot be read inside a media query (`@media (width < var(--x))` is invalid), so a
token alone does not reach the CSS. `@custom-media` generated by Style Dictionary would, but it
needs a PostCSS or Lightning CSS plugin in both Next.js and the Storybook Vite build.

## Decision

Add `semantic.breakpoint.*` tokens as the documented values, write the pixel values in the media
queries, and add a test that fails when a media query in design-system CSS uses a width that is not
a breakpoint token.

## Consequences

- One source of the values, enforced by a test, with no build plugin.
- If the plugin route ever becomes cheap, a new ADR can switch to `@custom-media`.
